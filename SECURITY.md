# Сообщения о безопасности

Исправления безопасности в первую очередь выпускаются для последней версии Luma Island. Это небольшой community-проект: гарантированного срока ответа пока нет.

Не публикуйте токены, личные данные, полные журналы с данными окружения и подробности уязвимости, которые могут навредить другим пользователям. Если для обсуждения нужен закрытый канал, создайте [issue](https://github.com/pyrrhuladev/luma-island/issues/new) с просьбой связаться приватно, без технических деталей и секретов. Сопровождающий согласует способ передачи информации.

Обычные ошибки интерфейса и совместимости отправляйте через [форму ошибки](https://github.com/pyrrhuladev/luma-island/issues/new?template=bug_report.yml).
