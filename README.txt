Luma Island 0.12.0 — «Тихий HUD» для Windows

Свёрнутый HUD показывает крупный FPS, выбранные показатели и кнопки музыки без логотипа.
Оригинальный графитовый значок приложения и трея сохранён.
Капсула не показывается в Alt+Tab и панели задач; используйте трей или Ctrl+Alt+Space.

ЗАПУСК
Windows 10 22H2 / Windows 11, x64.
Откройте Luma.Island.exe в папке новой версии.
Перед обновлением выйдите из старой версии через её меню в трее.
Программу не нужно устанавливать. .NET включён в portable-папку.
Сохраняйте EXE и все DLL в одной папке. Для переноса распакуйте весь ZIP.

АВТОЗАПУСК
Правый щелчок по капсуле или значку в трее → «Запускать вместе с Windows».
Галочка включает запуск после входа в Windows; повторное нажатие отключает его.
По умолчанию автозапуск выключен. Права администратора не требуются.
При переходе на новую portable-версию запустите её вручную один раз: путь автозапуска обновится.
Если запуск отключён средствами Windows, программа предложит открыть системную «Автозагрузку».

УПРАВЛЕНИЕ
Нажмите на капсулу, чтобы раскрыть или свернуть её.
Ctrl+Alt+Space — скрыть в трей / показать капсулу из любого приложения.
Ctrl+Alt+I — переключить пропуск кликов в игру.
Перетащите свёрнутую капсулу или заголовок раскрытой панели.
Положение сохраняется автоматически после перетаскивания и восстанавливается при запуске.
Правый щелчок по капсуле или значку в трее → «Положение»:
девять готовых позиций, выбор экрана при нескольких мониторах, «Закрепить положение».
Для свободного перетаскивания снимите отметку «Закрепить положение».
Play/Pause, предыдущий и следующий трек управляют текущей системной медиасессией.
Маленькие кнопки доступны и в свёрнутой капсуле; они не раскрывают панель.
Обложки доступны в обоих размерах панели и обрезаются по центру без искажения пропорций.
При смене трека название появляется сразу. Поздняя обложка повторно проверяется ограниченное число раз.
Обновление картинки обрабатывается и при тех же названии/исполнителе; старые асинхронные ответы отбрасываются.
Ползунок меняет системную громкость, кнопка динамика включает и выключает звук.
В трее: щелчок показывает капсулу и возвращает управление мышью, правый щелчок открывает меню.
«Скрыть в трей» / «Показать капсулу» доступны в контекстном меню.
Повторный запуск Luma показывает уже запущенную капсулу и возвращает управление мышью.
Скрытие в трей приостанавливает счётчики нагрузки, температур и FPS до восстановления.
Выход — в меню трея или в контекстном меню капсулы.

ПРОФИЛИ ИГР
Откройте «Профили игр» в меню HUD или значка в трее.
Добавьте .exe самой игры: новый профиль сохранит текущий HUD.
У каждого профиля свои положение, экран, прозрачность, масштаб и компоненты.
Можно записать текущий HUD в выбранный профиль кнопкой в окне профилей.
Изменения списка и переключателя применяются после нажатия «Сохранить».
Автопереключение по умолчанию выключено и может быть отключено в любой момент.
При включённой автоматике изменения HUD сохраняются в активный профиль игры.
После выхода из игры возвращаются обычные настройки. Alt+Tab в другое приложение
не сбрасывает профиль игры, пока она работает. При нескольких играх учитывается активное окно.
Выключение автопереключения оставляет текущий HUD на месте; дальнейшие изменения
сохраняются обычным способом. Пропуск кликов остаётся общей настройкой приложения.
Подробности: docs/profiles.md.

ПРОПУСК КЛИКОВ В ИГРУ
В меню HUD или трея включите «Пропускать клики в игру» либо нажмите Ctrl+Alt+I.
Панель свернётся и останется видимой, а мышь будет работать с окном под ней.
Показатели и музыка продолжают обновляться с прежней частотой.
Для кнопок музыки, перетаскивания или настроек выключите режим через Ctrl+Alt+I
либо щёлкните по значку Luma в трее. Повторный запуск программы тоже возвращает управление.
Ctrl+Alt+Space скрывает/показывает HUD, сохраняя режим пропуска кликов.
Режим по умолчанию выключен; выбранное состояние запоминается.
При конфликте Ctrl+Alt+I используйте трей. Если недоступны оба способа восстановления,
HUD остаётся управляемым. Прозрачность фона настраивается независимо от пропуска кликов.

ОФОРМЛЕНИЕ
При клике мышью обводки фокуса нет; при управлении клавиатурой фокус виден.
Правый щелчок по капсуле или значку в трее → «Настройки…» → «Внешний вид».
Ползунок «Прозрачность фона» регулирует её от 0% до 95%; готовые уровни также доступны.
У стекла полупрозрачный тонированный фон. Текст, значки и управление сохраняют собственную непрозрачность.
Размытие фона в этот режим не входит.
Прозрачность и масштаб восстанавливаются после перезапуска. Для новых настроек прозрачность составляет 60%.
На самых прозрачных уровнях текст получает небольшую тёмную тень для читаемости.

КОМПОНЕНТЫ И МОНИТОРИНГ
Правый щелчок по капсуле или значку в трее → «Настройки…» → «Показатели».
Раздельные переключатели для музыки, ползунка громкости, времени, даты, батареи, CPU, GPU, RAM, FPS, 1% Low и графика времени кадра.
«Громкость колёсиком» можно включить отдельно и использовать над любым островком.
Дополнительная галочка «Температура GPU» показывает градусы ядра NVIDIA через установленный драйвер.
При включённых нагрузке и температуре GPU они занимают две строки в одной колонке.
Температура по умолчанию выключена; без датчика показан прочерк с причиной в подсказке.
Опрос раз в две секунды; после отключения температуры сессия NVML закрывается.
Для температуры GPU не нужны отдельная программа, права администратора или FPS-сборщик FrameView.
Из нескольких доступных NVIDIA GPU показывается максимальная температура ядра.
Для CPU/RAM есть отдельные галочки и необязательный модуль датчиков:
«Компоненты → Настроить датчики CPU / RAM…». Установка модуля и PawnIO требует прав администратора.
Драйвер устанавливается пользователем отдельно с официального сайта; оверлей работает с обычными правами.
RAM показывает максимум доступных датчиков DIMM / SPD hub. Совместимость зависит от планок и платы.
Настройка, обновление и удаление: docs/sensors.md. Hotspot и VRAM в эту версию не входят.
Показатели в свёрнутой капсуле размещены в равных колонках с увеличенными отступами.
Положение и размер панели подстраиваются под выбранные компоненты.
CPU/GPU/RAM, FPS, 1% Low и график времени кадра по умолчанию выключены. Выбор сохраняется после перезапуска.
Батарея показывается только при наличии аккумулятора и питании от него.
При подключении питания индикатор батареи скрывается, надписи «От сети» нет.
CPU, GPU и RAM обновляются раз в две секунды; GPU — самый занятый движок.
CPU использует Processor Utility с учётом частоты и Turbo Boost, как средний CPU в Steam.
Он может превышать 100%; при недоступности счётчика резервный метод указан в подсказке.
Недоступные показатели показывают прочерк.
Выключение CPU/GPU/RAM полностью останавливает соответствующий сбор данных.
При выключении музыки отключаются подписки на системную медиасессию.

FPS АКТИВНОЙ ИГРЫ
Реальный FPS поступает через уже установленный NVIDIA FrameView SDK.
Источник проверялся в CS2. DLL NVIDIA в архив не включается.
Включение FPS, 1% Low или графика времени кадра запускает штатный сборщик FrameView; он использует дополнительные процессы.
Сессия Luma закрывается, когда все три игровых показателя выключены.
Вспомогательными процессами и службой управляет сам SDK NVIDIA.
Процессы FrameView могут остаться в памяти после отключения FPS; их расход нужно учитывать отдельно.
Без установленного SDK или доступных кадров отображается «FPS —» с пояснением.
Частота обновления монитора не выдаётся за FPS игры.

1% LOW И ВРЕМЯ КАДРА
Включаются отдельными галочками в меню «Компоненты», независимо от обычного FPS.
1% Low отображается в свёрнутом HUD и раскрытой панели.
График времени кадра в миллисекундах показывает последние 10 секунд в раскрытой панели; мини-графики нагрузки для него включать не требуется.
Источник — интервалы между Present игры (поле FrameView MsBetweenPresents).
График использует отдельные кадры и сохраняет пики при уменьшении числа точек для отрисовки.
При смене источника история сбрасывается, недоступные данные показываются прочерками и разрывами.
Новые переключатели сохраняются и в профилях игр. Подробности и источник: docs/frame-timing.md.

МИНИ-ГРАФИКИ
«Компоненты» → «Расширенный режим: мини-графики».
В раскрытой панели появляются графики выбранных CPU, GPU, RAM и FPS.
История хранится только в памяти: до 60 точек за две минуты.
Первые данные показываются на коротком интервале, который постепенно растёт до двух минут.
Неизвестные значения отображаются пропусками, при смене игры история FPS начинается заново.
Графики используют уже существующие измерения и не создают отдельного таймера.
В свёрнутом виде линии не перерисовываются.
Результаты сравнения ресурсов в CS2 находятся в resource-comparison.md рядом с программой.

ПЕРВАЯ ВЕРСИЯ
Музыка и обложка, громкость, часы и дата, батарея, мягкое раскрытие.
При питании от сети и при отсутствии батареи её индикатор скрыт.
Треки видны у плееров, которые публикуют системную медиасессию Windows.
Перемотка и история буфера в эту версию не входят.
При первом запуске окно стоит сверху по центру. Затем запоминает выбранное положение.
При отключении сохранённого монитора окно возвращается на доступный основной экран.
Автообновление не включено.

КАК УМЕНЬШЕНА НАГРУЗКА
WPF/C# вместо браузерной оболочки; основной интерфейс работает одним процессом.
Дополнительный сборщик кадров NVIDIA запускается только при включённом FPS, 1% Low или времени кадра.
SMTC и Core Audio работают по событиям, без фоновых PowerShell.
Обложка уменьшается до 128 px; одинаковые байты картинки повторно не декодируются.
Часы и батарея обновляются раз в минуту.
Анимации запускаются только при раскрытии и сворачивании.
Portable-сборка не сжимает DLL в память при запуске.

РАЗРАБОТКА
Исходники: src\Luma.Island.
Сборка: powershell -File build.ps1
Portable-сборка: powershell -File build.ps1 -Publish
Все проверки: powershell -File tools\Test.ps1
Архив релиза с документацией и лицензиями: powershell -File tools\Package.ps1
Нужен .NET 10 SDK. Скрипт использует локальную .tools\dotnet, если она есть.
Проверка запуска и рендера: Luma.Island.exe --verify <папка-результатов>
Диагностическое видимое окно в панели задач: Luma.Island.exe --ui-check
Журнал ошибок: %LOCALAPPDATA%\LumaIsland\errors.log
Настройки положения: %LOCALAPPDATA%\LumaIsland\placement.json
Настройки оформления: %LOCALAPPDATA%\LumaIsland\appearance.json
Настройки компонентов: %LOCALAPPDATA%\LumaIsland\components.json
Тесты положения: dotnet run --project tests\PlacementChecks -c Release -- work
Тесты компонентов: dotnet run --project tests\ComponentChecks -c Release -- work
Тесты расчётов нагрузки: dotnet run --project tests\PerformanceChecks -c Release
