# Знак Luma Island

Знак создан специально для Luma Island с помощью OpenAI ImageGen 4 ноября 2026 года. Это самостоятельный сгенерированный рисунок: мятная буква L и отдельная светлая точка на тёмной скруглённой плитке. Сгенерированный исходник сохранён в репозитории; последующая обработка ограничена техническим масштабированием и упаковкой в формат значков Windows.

Графические файлы Luma Island распространяются по [лицензии MIT проекта](../LICENSE). Сторонние библиотеки сохраняют собственные лицензии, перечисленные в [уведомлениях](THIRD_PARTY_NOTICES.md).

## Обновление значков

После замены исходного PNG выполните из корня проекта:

```powershell
.\tools\Build-Icons.ps1
```

Сценарий использует встроенные средства Windows PowerShell и WPF. Он масштабирует изображение целиком, сохраняет прозрачность, создаёт оба ICO и копирует оригинальный PNG в документацию. Исходное изображение остаётся неизменным.

Преобразование повторяется независимо дважды; SHA-256 результатов должен совпасть. Размеры, число прозрачных и полупрозрачных пикселей, контрольные суммы и проверка точной копии сохраняются в `work/branding/icon-build.json`. Это проверка воспроизводимости в текущей среде Windows; при смене системного кодировщика результаты следует проверить заново. Перед выпуском отдельно проверьте читаемость кадра 16 × 16 в трее.
