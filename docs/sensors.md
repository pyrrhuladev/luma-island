# Температуры CPU и оперативной памяти

Температуры CPU и RAM — необязательные компоненты, выключенные по умолчанию. Оверлей работает без прав администратора. Чтение аппаратных датчиков вынесено в отдельную локальную службу Luma: библиотека датчиков и драйвер не загружаются в процесс интерфейса.

## Настройка

1. Откройте **«Компоненты → Настроить датчики CPU / RAM…»** в меню капсулы или трея.
2. По ссылке в окне установите подписанную **Official edition** драйвера [PawnIO](https://pawnio.eu/). Драйвер скачивается и устанавливается пользователем отдельно; Luma не включает его в архив и не устанавливает автоматически.
3. Нажмите **«Установить / обновить модуль Luma»** и подтвердите запрос Windows. Установщик копирует модуль в защищённый каталог Program Files и регистрирует локальную службу `LumaIslandSensors` для текущего пользователя.
4. Включите **«Температура CPU»** и/или **«Температура RAM»**. Эти переключатели независимы от загрузки CPU и занятой памяти.

Температура GPU NVIDIA использует другой источник — установленную NVML — и не требует этого модуля. Для обычного запуска, музыки, часов, нагрузки и громкости модуль датчиков тоже не нужен.

## Показания

CPU показывает доступный датчик CPU Package на Intel или Tctl/Tdie на AMD. Поддержка зависит от процессора, драйвера и Windows; универсальная совместимость со всеми компьютерами не гарантируется.

RAM показывает максимум среди доступных модулей DIMM. У DDR5 это может быть датчик SPD hub: он измеряет температуру в месте установки датчика, а не максимум всех микросхем DRAM. На памяти без доступного датчика показаний не будет. Только название модели, тип DDR4/DDR5 и ёмкость не подтверждают доступность температуры.

Если включены и нагрузка, и температура, колонка показывает их в две строки. Если включены только градусы, проценты скрыты. Мини-графики остаются графиками нагрузки; температура не выдаётся за процент.

При ошибке, тайм-ауте, устаревшем ответе или отсутствии датчика отображается **«— °C»**, с причиной в подсказке. Нулём отсутствующие данные не заменяются. ACPI thermal zone не используется как подмена температуры CPU.

## Работа модуля

Интерфейс запрашивает только выбранные температуры в существующем цикле раз в две секунды. Служба принимает ограниченные локальные запросы CPU/RAM и возвращает показания; команд изменения частот, напряжений или вентиляторов в протоколе нет. Сетевой доступ не используется.

При отключении обоих температурных компонентов или закрытии интерфейса соединение закрывается, библиотека освобождается, аппаратный опрос прекращается. Установленная служба может оставаться в ожидании соединения. Точные затраты службы при чтении датчиков требуют отдельного измерения на поддерживаемом оборудовании; прежние замеры интерфейса их не включают.

Обновление portable-приложения само по себе не заменяет установленный модуль. После обновления используйте ту же кнопку установки модуля. Для удаления нажмите **«Удалить модуль Luma»**. Отдельно установленный PawnIO удаляется средствами Windows; Luma не удаляет драйвер, который может использовать другая программа.

### Если CPU и RAM одновременно стали показывать тире

В 0.8.0 обнаружено падение службы при позднем освобождении SPD-датчика памяти. Оно исправлено в 0.8.1. Обновите Luma и нажмите **«Установить / обновить модуль Luma»** в настройке датчиков; Windows попросит подтверждение администратора. Уже установленный PawnIO переустанавливать не нужно.

Подсказка **«Служба датчиков остановлена»** означает проблему службы, а не отсутствие термодатчика на памяти. Если ошибка повторяется после обновления модуля, укажите её время и версию модуля в issue. Полные журналы Windows могут содержать личные пути и идентификаторы пользователя — сначала удалите их из публикуемого фрагмента.

## Проверки совместимости

Автоматические проверки используют отдельные настройки и имитированные показания. Они проверяют выбор правильного датчика, исчезновение старых значений, протокол, ограничения доступа и интерфейс, не устанавливая службу или драйвер. Они не доказывают работу реального датчика на каждом ПК.

Сообщая о проблеме, укажите версию Luma и модуля, модель CPU/платы/памяти, версию PawnIO и текст подсказки. Не прикладывайте серийные номера, полную выгрузку SPD и личные журналы без удаления персональных данных.
