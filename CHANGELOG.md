# История изменений

## 0.8.0 — 2026-11-04

- Добавлены небольшие кнопки паузы, предыдущего и следующего трека в обычную и компактную свёрнутую капсулу. Они не запускают раскрытие или перетаскивание.
- Обводка фокуса убрана при клике мышью; управление клавиатурой сохраняет видимый фокус.
- Ctrl+Alt+Space теперь скрывает и показывает капсулу. Команды трея доступны в контекстном меню; щелчок по значку и повторный запуск восстанавливают окно.
- Скрытие в трей приостанавливает счётчики нагрузки, температур и FPS, сохраняя их настройки. Конфликт горячей клавиши объясняется в меню.
- Добавлены отдельные выключенные по умолчанию температуры CPU и RAM с необязательной локальной службой, библиотекой LibreHardwareMonitor и отдельно устанавливаемым PawnIO.
- Показания CPU Package / Tctl/Tdie и доступных DIMM показываются отдельно либо второй строкой рядом с нагрузкой. При отсутствии данных — прочерк и причина в подсказке; совместимость RAM зависит от оборудования.
- Установка и удаление модуля датчиков доступны из меню компонентов. Оверлей не требует повышения прав; установка службы требует подтверждения Windows.
- Кнопка буста отложена; предложение по совместимости и восстановлению настроек описано отдельно. Текущая версия не меняет параметры разгона или питания.

## 0.7.0 — 2026-11-04

- Добавлена сохраняемая «Компактная капсула»: меньше ширина, обложка и отступы, название трека остаётся; раскрытая панель полноразмерная.
- Раскрытие и сворачивание учитывают меняющуюся ширину и сохраняют положение окна при быстрых переключениях.
- Исправлено обновление обложек, приходящих позже названия или отдельным событием с теми же метаданными.
- Отсутствующая и ещё не обновившаяся обложка проверяется повторно с ограниченным бюджетом; поздние ответы старого трека отменяются.
- События плеера объединяются без параллельного чтения картинок; неизменившееся изображение повторно не декодируется.

## 0.6.0 — 2026-11-04

- Добавлена отключаемая температура ядра NVIDIA GPU через NVML уже установленного драйвера, без новых программ и прав администратора.
- Нагрузка и температура GPU отображаются в одной колонке, при совместном включении — в две строки с дополнительным местом.
- При отсутствии датчика показан прочерк с причиной; чтение останавливается при отключении компонента.
- Добавлены проверки NVML, совместимости настроек и отображения температуры.

## 0.5.2

- Добавлен пункт **«Запускать вместе с Windows»** в меню капсулы и трея. Автозапуск по умолчанию выключен и настраивается для текущего пользователя без прав администратора.
- Галочка автозапуска обновляется при открытии меню. Если запуск отключён средствами Windows, можно перейти в системную «Автозагрузку».
- При первом ручном запуске новой portable-версии обновляется путь уже включённого автозапуска. Системное отключение Windows сохраняется.
- Добавлены изолированные проверки регистрации автозапуска, переключения, переноса пути и обработки состояния Windows.

## 0.5.1

- Исправлены растянутые обложки: широкие и высокие изображения обрезаются по центру перед уменьшением, сохраняя пропорции.
- Выравнены размеры и скруглённое обрезание обложек в свёрнутой и раскрытой панели.
- Нормализован DPI подготовленной обложки; маленькие исходники не увеличиваются при декодировании.
- Добавлены проверки геометрии, крайних соотношений сторон, DPI и рендера обложок в обоих размерах интерфейса.

## 0.5.0

- Дополнительные компоненты CPU, GPU, RAM и FPS включаются по отдельности; их выбор сохраняется между запусками.
- Добавлены мини-графики выбранных показателей в раскрытой панели: до 60 точек за две минуты, пропуски для недоступных данных и новая история FPS при смене приложения.
- Расширены уровни прозрачности стекла до 75%; для текста на прозрачном фоне добавлена тень. Матовое оформление остаётся непрозрачным.
- Для FPS используется установленный NVIDIA FrameView SDK. Библиотеки NVIDIA не включаются в сборку; выключение FPS завершает сессию Luma, а жизненным циклом службы и вспомогательных процессов управляет SDK.
- Обновлены компоновка показателей, адаптация высоты панели и сохранение её положения при раскрытии и сворачивании.
